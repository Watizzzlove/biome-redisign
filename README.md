# BIOME — Mobile App UI/UX Redesign & Design System

Интерактивная презентация кейса редизайна мобильного приложения **BIOME** — персонального AI-ассистента по здоровью.

## 🚀 Live Demo (GitHub Pages)
👉 [https://watizzzlove.github.io/biome-redisign/](https://watizzzlove.github.io/biome-redisign/)

---

## 📱 Ключевые экраны кейса

1. **Главный экран (Dashboard & Hub)** — *Редизайн оригинальных экранов 14–15*:
   - Упорядоченная визуальная иерархия без неонового шума и лишних рамок.
   - Фотореалистичные 3D-ассеты в карточках челленджей (рацион, здоровые привычки).
   - Интуитивный счетчик питания и шкала заполнения карты здоровья (20%).
   - Монолитный таб-бар с сохранением центральной кнопки AI-ассистента.

2. **Индикаторы здоровья и Дашборд шагов** — *Редизайн оригинальных экранов 17–18*:
   - 7-дневный дашборд с системными датами без рамок, выровненными по горизонтальной базовой линии.
   - Акцент на текущем дне с подписью «Сегодня».
   - 12-колоночная внутрисуточная гистограмма шагов с подсветкой вечернего пика (18:30) и временными слотами.
   - 6 синхронизированных карточек с крупными 3D-моделями единого масштаба (пульс, сон, стресс, биовозраст, вес, гидратация).

3. **AI-Чат с персональным ассистентом** — *Редизайн оригинального экрана 20*:
   - Лаконичный центрированный хедер бренда `biome`.
   - Карточки-сниппеты рекомендаций по рациону в потоке сообщений.
   - Контекстные чипсы быстрого ввода («Что съесть после зала?», «Оценить фото блюда 📸»).
   - Эргономичный инпут-бар с микрофоном и вложением.

---

## 🎨 Особенности презентации

- **Интерактивный переключатель тем (Light / Dark)**: Все макеты и сайт мгновенно адаптируются под выбранную тему.
- **Режим сравнения (Было vs Стало)**: Возможность детально сопоставить оригинальные экраны приложения с обновленным дизайном.
- **Модальный просмотр (Lightbox)**: Кликните по любому экрану для изучения деталей в разрешении 2x.
- **Готовая дизайн-система**: Токены, шрифтовые стили Inter, радиусы скруглений, сетка 8pt и паритет тем.
